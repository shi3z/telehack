# Telehack テストツール

一人でも全機能を検証できるツール群。仮想参加者はヘッドレスChromium+フェイクカメラで動く
「本物のブラウザ参加者」なので、WebRTCの映像・データメッセージ・自動移動まで実際に動作する。

## 準備(初回のみ)

```bash
../.venv/bin/pip install playwright
../.venv/bin/playwright install chromium
```

## e2e.py — 全機能自動テスト

```bash
cd test && ../.venv/bin/python e2e.py
```

テスト用ハッカソンを作成し、主催者+仮想参加者4名(赤チーム/青チーム)で以下を自動検証して
PASS/FAIL レポートを出す(約5分)。終了時に元のハッカソンへ復元する。

- ワンタイムURL認証(1回のみ有効・再利用拒否)
- チーム作成→ブレイクアウトルーム自動生成
- ワンボタン送出/召集での全員自動移動
- ルーム内の相互映像表示・入室での自動録画
- 全ルームお知らせ(トースト)・共有タイマー表示
- 発表モード: ランダム順・発表映像の全ルーム配信・時間切れの自動送り
- 作品登録(UI)・匿名/顕名切替・投票ルール・得票集計
- 作品プレイ録画(ヘッドレスでは画面キャプチャ不可のためWARNになる場合あり)
- 結果発表(2位→1位、ドラムロール演出)・再発表拒否
- 全員退出→録画MP4自動保存・署名付きURLダウンロード

## demo.py — 仮想参加者シミュレーター(手動確認用)

```bash
cd test && ../.venv/bin/python demo.py           # 6人
cd test && ../.venv/bin/python demo.py 10 --works  # 10人+デモ作品登録
```

**アクティブなハッカソン**に仮想参加者を登録し、各チームルームに入室させて常駐させる
(チームがなければデモチームを自動作成)。その状態で自分のブラウザから管理画面を操作すると:

- 📢 お知らせ → 仮想参加者の画面にトースト表示
- 🚪 召集/送出 → 全員が全体会場⇔チームルームへ自動移動
- ⏱ タイマー、🎤 発表モード、🏆 結果発表 もすべて反応する

Ctrl+C で終了(仮想参加者は名簿から自動削除)。

## gen_faces.py — 仮想参加者の顔・挨拶動画生成

```bash
cd test && ../.venv/bin/python gen_faces.py
```

klein (FLUX.2, `100.104.204.50:8020`) で参加者6人+主催者MCのWebカメラ風ポートレートを生成し、
oracle (`tsuginosuke:8878`) で「カメラに手を振って挨拶する」動画に変換、
Chromiumフェイクカメラ用の y4m として `assets/` に保存する。生成済みファイルはスキップされる。

## scenario.py — ハッカソン完全自動シナリオ

```bash
cd test && ../.venv/bin/python scenario.py --fast  # 各フェーズ約1分の短縮版
cd test && ../.venv/bin/python scenario.py         # 本番 (ディスカッション/開発 各5分)
```

生成した顔をカメラ映像に持つ仮想参加者6人+MCで、イベントを最初から最後まで自動進行する:

1. 全体会場に集合して挨拶(全篇録画開始)
2. 主催者MCがステージ配信でテーマ発表
3. ディスカッション(チームルーム+共有タイマー)
4. 開発タイム(各チームが作品URLを登録)
5. 発表モード(各チーム持ち時間制・自動送り)
6. クロージング

各フェーズのスクリーンショットは `assets/scenario-shots/`、録画MP4は管理画面の録画タブに残る。
実行のたびに「デモハッカソン」を作り直す(録画は削除されない)。
